# Level 7: boss fights

Everything from Levels 1–6, stacked: fix the defect you can see, and the next one was hiding right behind it.

**Skills:** Several interacting problems; fixing one exposes the next. Symptom only, no per-defect hints.

**Mastery checkpoint:** Solve one with no hints and write the post-mortem.

Run one: `dotnet run -c Release --project levels/L07-boss-fights/exercises/<id>` (expect `FAIL`), work it as described in the [top-level README](../../README.md), and only then open the solution.
