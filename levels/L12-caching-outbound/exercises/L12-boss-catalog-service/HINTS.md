# Hints (open one at a time)

<details><summary>Hint 1: which tool?</summary>

Start with the budget that fails hardest and the tool this level taught you (counters, SQL counts, retained memory). Expect more than one cause; list every candidate before changing anything.
</details>

<details><summary>Hint 2: where?</summary>

Follow the evidence: which counter or frame is anomalous? Each defect is one you have met in this level's exercises.
</details>

<details><summary>Hint 3: why?</summary>

For each suspect, name the earlier exercise it resembles and re-measure after each fix; fixing the biggest first changes what the next one looks like.
</details>
